GAME HUB
========
Open GAME_HUB.html to see the game menu.

Everything in this folder is self-contained HTML/JavaScript made for this collection, so the games can be opened locally without a game website.

Games included:
Snake, Clicker, Reaction Test, Dodge, Tic Tac Toe, Memory Match, Pong, Falling Blocks, Number Guess.

Note: this collection is not intended to bypass school or network restrictions.
